# Search Intent Analysis

## Target Query

How to Build a Responsive Website

## Primary Intent

Informational

## User Goal

The user wants to learn how responsive websites
are created and how different techniques can be
implemented.

## Questions the Article Should Answer

1. What is responsive web design?
2. Why is responsive design important?
3. How do you create a responsive layout?
4. What is mobile-first design?
5. How do CSS media queries work?
6. How should images behave on smaller screens?
7. How should responsive websites be tested?
8. What common mistakes should beginners avoid?

## Content Approach

The article will teach the reader through:

- Explanations
- Step-by-step instructions
- CSS examples
- Best practices
- Common mistakes
- FAQ answers

## Commercial Content

The article will avoid aggressive sales messaging
because the primary search intent is informational.

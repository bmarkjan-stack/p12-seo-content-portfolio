# Sample 3 — Search Intent

## Topic

What Is a REST API and How Does It Work?

## Primary Search Intent

Informational

## Search Intent Explanation

The reader is looking for an understandable explanation of
REST APIs, how they work, and how applications communicate
with servers.

The reader may have encountered REST APIs while learning
web development but may not understand concepts such as:

- API
- REST
- endpoint
- HTTP method
- request
- response
- JSON

## Target Audience

- Beginner web developers
- Students learning web development
- Junior developers
- Technical users who want a basic REST API explanation

## User Questions

The article should answer:

1. What is an API?
2. What does REST mean?
3. What is a REST API?
4. How does a REST API work?
5. What is an API endpoint?
6. What are GET, POST, PUT, and DELETE?
7. What is JSON?
8. How does a client communicate with a REST API?
9. What is a REST API example?
10. How is a REST API used in web applications?

## Content Goal

Explain REST APIs in beginner-friendly language while
providing practical technical examples.
